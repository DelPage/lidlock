# LidLock 1.2.1

LidLock now keeps the lid-closed mode focused on staying awake while macOS
continues to manage Lock Screen behavior.

## Download

Apple signs the attached `LidLock.dmg` with Developer ID and notarizes it.
Gatekeeper validates both the app and disk image.

SHA-256:

```text
3c760d3c33c738e73f24442422a9aed4bd8201aefdd6800afbf26bc24f642bc2  LidLock.dmg
```

## What Changed

- Renamed the lid-closed mode to **Stay Awake with Lid Closed**.
- The mode no longer issues a display sleep command when the lid closes. This
  removes LidLock's direct Lock Screen trigger. macOS Lock Screen settings still
  apply.
- LidLock reads the lid-close sleep setting back before showing **Active** and
  holds a stronger system sleep assertion while the mode is active.

## Stay Awake with Lid Closed

1. Install LidLock in the Applications folder.
2. Open LidLock and choose **Stay Awake with Lid Closed**.
3. Approve the macOS administrator request.
4. Close the lid.

Your Mac can stay awake with its lid closed. Your Lock Screen settings
still apply. Choose **Normal Sleep** when you want the usual macOS sleep
behavior again.

If you prefer fewer password prompts, Settings can install an optional signed
helper that changes only the lid sleep setting.

## Replacing Older Copies

Before installing this version, choose **Normal Sleep**, turn off the optional
helper and Open at login, quit LidLock, and remove older copies. Install the new
copy in the main Applications folder.

The [Getting Started guide](https://github.com/DelPage/lidlock/blob/main/GETTING_STARTED.md#replace-older-copies)
has the complete cleanup steps.

## Requirements

- macOS 13 Ventura or newer.
- A MacBook for the lid-closed mode. Other Macs can still use the awake and
  display controls.

## Privacy

LidLock has no accounts, analytics, telemetry, or advertising. It does not
contact any server while you use it. The optional helper stays on your Mac and
changes only the lid sleep setting.

Privacy policy: https://github.com/DelPage/lidlock/blob/main/PRIVACY.md
