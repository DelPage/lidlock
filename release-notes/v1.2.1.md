# LidLock 1.2.1

- Renamed the mode to **Stay Awake with Lid Closed**.
- The mode no longer forces the Lock Screen. Your macOS Lock Screen settings
  continue to apply.
- Improved reliability when starting and maintaining the mode.

Requires macOS 13 or later. Lid modes require a MacBook. Other Macs can use the awake and display controls.

The installer is signed with Apple Developer ID and notarized by Apple.
