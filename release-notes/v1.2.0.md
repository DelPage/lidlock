# LidLock 1.2.0

Introduces four sleep modes, Walk Away, a first launch guide, and menu bar
access.

## Download

The attached `LidLock.dmg` is signed with Apple Developer ID and notarized by
Apple.

SHA-256:

```text
56fcf464a2937557661f1b2c49d8f8d1ec465ac9dee36a9415e239a7c37e8a95  LidLock.dmg
```

## What Changed

- Replaced separate power switches with four sleep modes.
- Added **Keep Running with Lid Closed** so work can continue after the lid
  closes while the displays are off.
- Added a first launch guide for the modes, Walk Away, menu bar access, and
  approvals.
- Added Walk Away as a separate action that turns off the display without
  stopping work.
- Added the Support LidLock page and donation choices.

**Keep Running with Lid Closed** was renamed **Stay Awake with Lid Closed** in
version 1.2.1.

## Replacing Older Copies

Before installing, choose **Normal Sleep**, turn off **Allow lid changes without
a password** and **Open at login**, quit LidLock, and remove older copies.

See the [replacement steps](https://github.com/DelPage/lidlock/blob/main/GETTING_STARTED.md#replace-older-copies).

## Requirements

- macOS 13 Ventura or newer.
- A MacBook for modes that use the lid. Other Macs can still use the awake and
  display controls.

## Privacy

LidLock has no accounts, analytics, telemetry, advertising, or automatic
network access while it runs.

Privacy policy: https://github.com/DelPage/lidlock/blob/main/PRIVACY.md
