LidLock now makes the lid closed option easy to find and understand.

## What Changed

- Replaced separate power switches with four clear sleep modes.
- Added **Keep Running with Lid Closed** so the Mac and apps continue after the
  lid closes while all displays turn off.
- Added a first launch guide for modes, Walk Away, the menu bar, and approvals.
- Made Walk Away a separate action that turns off the display without stopping work.
- Kept LidLock available in the menu bar when its window closes.
- Added the Support LidLock page and donation choices.
- Signed and notarized both the app and disk image.

## Keep Running with Lid Closed

1. Install LidLock in the Applications folder.
2. Open LidLock and choose **Keep Running with Lid Closed**.
3. Approve the macOS administrator request.
4. Close the lid.

The displays turn off while your Mac and apps keep running. Choose **Normal
Sleep** when you want the usual macOS sleep behavior again.

If you prefer fewer password prompts, Settings can install an optional signed
helper that changes only the lid sleep setting.

## Replacing Older Copies

Before installing this version, choose **Normal Sleep**, turn off the optional
helper and Open at login, quit LidLock, and remove older copies. Install the new
copy in the main Applications folder.

The [Getting Started guide](https://github.com/DelPage/lidlock/blob/main/GETTING_STARTED.md#replace-older-copies)
has the complete cleanup steps.

## Requirements

- macOS 13 Ventura or newer.
- A MacBook for the lid closed mode. Other Macs can still use the awake and
  display controls.

## Privacy

LidLock has no accounts, analytics, telemetry, or advertising. It does not
contact any server while you use it. The optional helper stays on your Mac and
changes only the lid sleep setting.

Privacy policy: https://github.com/DelPage/lidlock/blob/main/PRIVACY.md
