# LidLock 1.2.0

- Replaced separate power switches with four sleep modes.
- Added **Keep Running with Lid Closed** so work can continue after the lid
  closes while the displays are off.
- Added a first launch guide for the modes, Walk Away, menu bar access, and
  approvals.
- Added Walk Away as a separate action that turns off the display without
  stopping work.
- Added the Support LidLock page and donation choices.

**Keep Running with Lid Closed** was renamed **Stay Awake with Lid Closed** in
version 1.2.1.

Requires macOS 13 or later. Lid modes require a MacBook. Other Macs can use the awake and display controls.

The installer is signed with Apple Developer ID and notarized by Apple.
