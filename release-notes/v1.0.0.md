# LidLock 1.0.0

- Added controls for keeping the Mac or display awake.
- Added Walk Away to turn off the display without stopping work.
- Added Normal Sleep to restore the usual macOS sleep behavior.

Requires macOS 13 or later. Lid modes require a MacBook. Other Macs can use the awake and display controls.

The installer is signed with Apple Developer ID and notarized by Apple.
