# LidLock 1.0.0

Initial public release of LidLock for macOS.

## Download

The attached `LidLock.dmg` is signed with Apple Developer ID and notarized by
Apple.

SHA-256:

```text
1bd59b93a726cca08aff3bf222fb70d9e88d5c680ff474e07e20714f23923799  LidLock.dmg
```

## What Changed

- Added controls for keeping the Mac or display awake.
- Added Walk Away to turn off the display without stopping work.
- Added Normal Sleep to restore the usual macOS sleep behavior.

## Requirements

- macOS 13 Ventura or newer.
- A MacBook for modes that use the lid. Other Macs can still use the awake and
  display controls.

## Privacy

LidLock has no accounts, analytics, telemetry, advertising, or automatic
network access while it runs.

Privacy policy: https://github.com/DelPage/lidlock/blob/main/PRIVACY.md
