# LidLock 1.0.1

Fixes battery behavior and approval prompts.

## Download

The attached `LidLock.dmg` is signed with Apple Developer ID and notarized by
Apple.

SHA-256:

```text
d4e2e1b97ffcf1315f8915a9519ea328dffefde65bd02f3ccd9726aa0ed44c47  LidLock.dmg
```

## What Changed

- Prevented duplicate password prompts when enabling lid closed mode on
  battery.
- Fixed cases where LidLock could reverse the selected lid setting while on
  battery.
- Kept the menu bar and main window in sync while settings change.
- Fixed Open at login cleanup while macOS approval is pending.

## Requirements

- macOS 13 Ventura or newer.
- A MacBook for modes that use the lid. Other Macs can still use the awake and
  display controls.

## Privacy

LidLock has no accounts, analytics, telemetry, advertising, or automatic
network access while it runs.
