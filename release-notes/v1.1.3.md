# LidLock 1.1.3

- Closing the main window leaves LidLock in the menu bar.
- **Open LidLock** brings the window back.
- **Quit LidLock** exits the app and restores normal sleep.
- Hovering over the menu bar icon shows the current sleep setting.

Requires macOS 13 or later. Lid modes require a MacBook. Other Macs can use the awake and display controls.

The installer is signed with Apple Developer ID and notarized by Apple.
