# LidLock 1.1.3

LidLock now stays in the macOS menu bar after its window closes.

## Download

The attached `LidLock.dmg` is signed with Apple Developer ID and notarized by
Apple.

SHA-256:

```text
fe735f2a9cebdbd5807163d4099c75df6141d70ca36aa91265562caf1d78e8af  LidLock.dmg
```

## What Changed

- Closing the main window leaves LidLock in the menu bar.
- **Open LidLock** brings the window back.
- **Quit LidLock** exits the app and restores normal sleep.
- Hovering over the menu bar icon shows the current sleep setting.

## Requirements

- macOS 13 Ventura or newer.
- A MacBook for modes that use the lid. Other Macs can still use the awake and
  display controls.

## Privacy

LidLock has no accounts, analytics, telemetry, advertising, or automatic
network access while it runs.
