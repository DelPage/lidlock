# LidLock 1.2.3

- Keep Screen On and Stay Awake now say “Lid Open” in the window and menu.
- The closed lid choice explains that work keeps running while the MacBook display turns off.
- Added Display Off Without Locking guidance and a link to Lock Screen settings in the window, menu, and Settings.
- Mode descriptions remain readable instead of being cut off.

These notes describe version 1.2.3. The [current modes](https://github.com/DelPage/lidlock/blob/main/GETTING_STARTED.md#modes) keep tasks running without automatic locking or changing macOS lock settings.
